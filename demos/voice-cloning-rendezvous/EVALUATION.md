# 声音克隆模型验收标准

这份赛马不以单个主观印象决定模型。三个候选使用同一参考音频、同一准确参考文本、同一组中英文短句和同一组长程分段；先盲听音频，再查看模型名和性能数据。

## 评分表（总分 100）

| 维度     | 权重 | 具体检查                                                                  |
| -------- | ---: | ------------------------------------------------------------------------- |
| 音色身份 |   25 | 与参考人声是否像同一人；中文、英文和长程后半段是否仍保持身份              |
| 可懂度   |   20 | 是否漏字、吞字、重复、幻觉；数字、英文缩写和专有名词是否正确              |
| 自然度   |   20 | 语速、重音、停顿、句尾语气；是否存在明显电音、爆音或机械节奏              |
| 长程稳定 |   15 | 64 段、4 轮中英交替之后是否音色漂移、音量变化、情绪失控；段间接缝是否突兀 |
| 等待体验 |   15 | 模型加载、首段耗时、RTF 中位数与 P90；20 分钟视频何时能切到连续后缀       |
| 工程成本 |    5 | 模型和运行时体积、峰值显存、许可、Windows/macOS 部署难度                  |

## 建议的实际验收顺序

1. 结果页默认隐藏模型名与性能。只播放“参考人声”和三份中文 one-shot，不先点“揭晓模型”。
2. 播放 English one-shot，检查跨语言后音色身份和口音。
3. 展开每张模型卡的“抽听同一句四轮复现 + 最末段”。前四条文本完全相同但随机种子不同，最适合检查音色与语气稳定；再听最末段检查任务尾部。
4. 再比较 RTF、P90、加载时间和显存；音质不达标的高速模型不进入工程候选。
5. 在同屏模拟中分别选择冷启动与已加载，确认白色后缀何时追上播放头。

波形诊断只负责拦截明显坏产物：接近 100% 静音、持续削波、非有限数值或无法解码。它不能代替音色相似度和自然度的人工盲听。

## 产物口径

- `results/local/reference.wav`：统一 one-shot 参考人声。
- `results/local/<model>/zh-one-shot/joined.wav`：中文直接对比。
- `results/local/<model>/en-one-shot/joined.wav`：英文直接对比。
- `results/local/<model>/long-run-bilingual/joined.wav`：多段长程稳定性对比。
- `results/local/<model>/benchmark.json`：逐段耗时、音频时长、RTF 与显存数据。
- `results/local/aggregate.json`：结果页读取的统一索引。
- `results/local/validation.json`：对缺失、不可解码、时长不符、全静音和严重削波的自动检查。

RTF 只用于预测，白色生成范围只由真实完成的音频段推进。若没有可靠时间覆盖，界面不能提前宣称克隆音轨可播放。

赛马 Demo 没有绑定一条真实视频时间轴，因此同一句在三个模型中的输出时长中位数被用作共同 Cue 覆盖代理，避免语速较快的模型凭空获得更长覆盖。正式 Workbench 必须改用字幕 Artifact 的真实 Cue 起止时间。
