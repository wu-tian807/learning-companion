预测只决定 UI 告知用户何时可能切换；真正切换始终以白色实际覆盖条为准。

调度规则

  1. 生成顺序固定为“从结尾向前”，不依赖章节，也不伪造可播放范围。
  2. RTF 用来预测第一次相遇位置；每完成一个真实音频块，白色覆盖条才向左增长。
  3. 播放头进入白色范围后切换到克隆音轨；从该点到结尾已经连续可用。
  4. 拖动进度条只重新计算相遇点，不丢弃已经完成的后缀。
