Media AI 与通用 Workbench 问答基建

目标不是给 Video Workbench 临时塞几个 AI 按钮，而是建立一条可复用主路：媒体打开后立即播放，字幕与配音按 Cue 增量可用；每个 Workbench 自己描述选区语义与上下文，公共问答层统一管理会话体验，再通过 TaskDefinition、GenerationTask 和 AgentProvider 执行。

已实现基建 待实现 已有底座 + 待扩展 用户流程
播放不等待 AI

打开媒体首先进入原始播放链；分离、转写、翻译与配音全部作为可取消后台作业。

Workbench 拥有媒体语义

框选、页码、DOM Range、CFI、时间段等 Anchor 都由具体 Workbench 创建和解释。

公共问答层不直连 Provider

它只统一会话 UI 与任务编排；Agent 请求仍走 TaskDefinition → GenerationTask → AgentProvider。

派生产物进入 Asset 体系

缓存使用 Artifact；需要长期学习、引用或编辑的配音视频/摘要再成为 Asset、Attachment 或 Link。
